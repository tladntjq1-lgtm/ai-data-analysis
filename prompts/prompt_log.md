# LLM 활용 기록 (Prompt Log)

책 Chapter 01 - 25~26절 참고. LLM을 사용한 분석은 코드뿐 아니라
"어떤 질문을 했는지"도 재현성을 위한 작업 기록이다.

## 저장 시 주의할 점

- API 키를 기록하지 않는다.
- 개인정보(실명, 연락처, 주소, 결제정보 등)를 포함하지 않는다.
- 비공개 데이터 원문을 그대로 붙이지 않는다.
- 필요하면 컬럼명과 샘플 값을 익명화한다.
